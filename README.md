# PocketCalc

Калькулятор на C# и WPF для Windows. Доработанная версия проекта Skyli120x60/calculator.

Изменения: новая сине-графитовая палитра с янтарными кнопками, заголовок PocketCalc, переключение светлой и тёмной темы, подсказки клавиш и последний расчёт под клавиатурой. История больше не стирается при запуске; подтверждённые расчёты сохраняются. Неполное выражение больше не показывает устаревший результат.

## Запуск

Нужен .NET 8 SDK или новее. Откройте VakhrushevCalculator.sln в Visual Studio либо выполните из этой папки:

```
dotnet run --project VakhrushevCalculatorApp/VakhrushevCalculatorApp.csproj -c Release
```

Операции: +, -, *, /, целая степень ^ и скобки. Ввод с клавиатуры: Enter — вычислить и сохранить, Esc — очистить, Backspace — удалить символ. Точка и запятая подходят для дробной части.

История и тема хранятся в %LocalAppData%\PocketCalc. В интерфейсе отображается последний подтверждённый расчёт; полный журнал остаётся в history.json.

Проверка: dotnet test VakhrushevCalculator.sln -c Release
